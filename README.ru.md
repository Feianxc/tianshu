# Tianshu 天枢

**Самостоятельно размещаемая панель управления для серверов, устройств, сервисов, проектов и репозиториев одного человека — с MCP-сервером только для чтения, чтобы ИИ-агенты видели то же, что и вы.**

Tianshu (天枢, *Дубхе*, первая звезда Большой Медведицы) — это один исполняемый файл на Go со встроенной веб-консолью. Он с первого взгляда отвечает на вопрос: **нужно ли сейчас моё вмешательство?** Tianshu ведёт каталог того, чем вы владеете, собирает реальные данные о состоянии, сводит их в короткий список замечаний и отдаёт ту же модель чтения ИИ-агентам через [Model Context Protocol](https://modelcontextprotocol.io).

## Возможности

- Устройства, сервисы, проекты, репозитории и **ссылки** на учётные данные, разделённые по рабочим пространствам (личное, компания, клиенты).
- Живая звёздная карта: каждое пространство — орбита, форма и цвет показывают состояние; при каждом отчёте хоста к центру летит импульс.
- Полоса телеметрии: реальные отчёты за последние 60 минут по каждому хосту. Нет данных — видна пустота, а не «OK».
- Состояние, свежесть, жизненный цикл и приёмка учитываются отдельно; устаревшие данные никогда не считаются здоровыми.
- Замечания без дублей, которые закрываются сами, когда проблема исчезает; отложить на день, неделю или месяц.
- Агент для Linux и Windows, сбор по SSH только для чтения, проверки HTTP, TCP и TLS.
- Контроль открытости SSH: вход по паролю, неудачные входы, fail2ban, отпечатки ключей.
- MCP-сервер (Bearer-токены и OAuth 2.1), изоляция пространств, никаких хранимых секретов, аудит каждого вызова.
- Вход через сопряжение устройств, палитра команд (`Ctrl K`), тёмная и светлая темы, мобильная вёрстка и оболочка для Android.

## Быстрый старт

Нужны Go 1.27+ и Node.js 20+.

```bash
git clone https://github.com/Feianxc/tianshu.git && cd tianshu
bash scripts/build.sh
export WANGLOU_DATA=./data
.build/wanglou import examples/catalog   # необязательно: вымышленные демонстрационные данные
.build/wanglou init                      # один раз показывает токен администратора
.build/wanglou serve                     # http://127.0.0.1:8787
```

Подробнее — в разделах [Архитектура](docs/ARCHITECTURE.md) и [Развёртывание](docs/DEPLOYMENT.md) (на английском). Интерфейс консоли пока на упрощённом китайском.
